## Тема: Жизненный цикл  разработки ПО (SDLC)


**Жизненный цикл** – это путь который проходит продукт: от задумки до вывода из эксплуатации \
\
Этапы ЖЦ ПО:
1.	Планирование и анализ требований (руководитель проекта, заказчик, владелец продукта, бизнес-аналитик, стейкхолдеры – компании, которые заинтересованы в производстве продукта или посредники)
      *	Описание задач, которые должен решать продукт
      *	Опрос стейкхолдеров
      *	Аудитория
      *	Оценка ресурсов
      *	Согласования критериев
2.	Определение требований (руководитель проекта, владелец продукта,  команда разработки, архитектор)
      *	Оценка рисков
      *	Выбор методологии работы
      *	Описание пользовательских сценариев
3.	Проектирование ()

| Верхнеуровневое проектирование | Низкоуровневое проектирование | 
|-------|----------|
| Основные компоненты системы – например, модули (Файлы которые имеют определенную функциональность), сервисы или подсистемы      |  Принцип работы отдельных компонентов системы. (Прописывают каждый элементы, следовательно больше работы)    | 
| Принцип взаимодействия этих компонентов между собой	   | Алгоритмы, структуры данных(файлы в которых хранятся данные) и логика работы внутри каждого модуля     | 
|Общая архитектура системы – например, клиент-серверная архитектура или микросервисы	    | Детали реализации – например, какие классы, методы или функции будут созданы  | 
|Зависимость решений от других систем|Взаимодействие  с БД, API или другими внешними системами|
|Прототип интерфейса	||

5.	Разработка
6.	Тестирование
7.	Развертывание
8.	Поддержка и сопровождение
9.	«Смерть» ПО

  ## Как выбрать правильную модель SDLC
  **На какие вопросы нужно ответить:**

- Есть ли у команда постоянный доступ к заказчику?
- Поддерживает ли спонсор гибкие методологии?
- Насколько вы уверены в том, что команда понимает ваша видение?
- Может ли команда сама принимать решения?
- Можно ли поставлять продукт частями?
- Как часто меняются требования к продукту?
- Какой размер команды?
- Насколько критичные проблемы будут в случае дефектов?
- Насколько большой опыт у команды?

- Резюме
     - SDLC, или жизненный цикл разработки ПО — последовательные этапы, из которых состоит разработка. Работа по этапам помогает избежать хаоса в процессах.
     
     - Основные этапы разработки: анализ требований, определение требований, проектирование, разработка, тестирование, развертывание, поддержка и вывод из эксплуатации.
     
     - Чтобы жизненный цикл не ломался, при разработке опираются на модели жизненного цикла. Самые строгие из них — каскадная и V-образная. При работе по этим моделям не получится перейти с одного этапа на предыдущий. Самые гибкие — Agile-методы. С ними можно выпускать недоработанное решение и улучшать его короткими итерациями.
     
     - Чтобы упростить управление разработкой, можно использовать системы для управлениями проектами. Например, Kaiten подходит для работы с любой моделью SDLC. А среди возможностей таск-трекера: визуализацию с помощью канбан-досок, готовые доски для спринтов, диаграмма Ганта, инструменты для ведения и хранения документации по проекту.
