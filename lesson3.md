## Общая характеристика векторов и строк

Вектор (`std::vector`) и строка (`std::string`) являются важными базовыми контейнерами стандартной библиотеки C++. Они обладают следующими общими свойствами:
- Хранят свои элементы в **непрерывном фрагменте памяти**.
- Предоставляют **доступ к элементам по индексу**.
- Позволяют **эффективно добавлять новые элементы в конец**.

---

## Контейнер std::vector

### Определение и характеристики
В стандартной библиотеке C++ вектором (`std::vector`) называется **динамический массив**, который:
- Обеспечивает быстрое добавление новых элементов в конец.
- Меняет свой размер при необходимости.
- Гарантирует отсутствие утечек памяти (это будет рассмотрено в других параграфах).

### Подключение
Для работы с вектором необходимо подключить заголовочный файл:
```cpp
#include <vector>
```

### Тип элементов
- Все элементы вектора должны быть **одного типа**.
- Этот тип должен быть известен на этапе компиляции программы.
- Тип задаётся в угловых скобках после `std::vector`:
  - `std::vector<int>` — вектор целых чисел типа `int`.
  - `std::vector<std::string>` — вектор строк.
- `std::vector` сам по себе не является типом данных — это **шаблон**, в который требуется подставить параметры (тип элемента), чтобы получить конкретный тип данных. Подробнее о шаблонах — в параграфе «Шаблоны».

### Инициализация вектора

#### Список инициализации
Пример программы, которая заполняет вектор элементами и печатает их через пробел:
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    for (int elem : data) {
        std::cout << elem << " ";
    }
    std::cout << "\n";
}
```
Здесь вектор инициализируется через **список инициализации**, в котором элементы перечислены через запятую.

#### Другие способы инициализации
Можно указать количество элементов и (при необходимости) образец элемента:
```cpp
#include <string>
#include <vector>

int main() {
    std::vector<std::string> v1;           // пустой вектор строк
    std::vector<std::string> v2(5);        // вектор из пяти пустых строк
    std::vector<std::string> v3(5, "hello"); // вектор из пяти строк "hello"
}
```

## Обращение к элементам вектора

### Доступ по индексу
Вектор хранит элементы в памяти последовательно, поэтому по индексу можно быстро найти положение элемента в памяти. Индексация начинается с нуля:
```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
int a = data[0];      // начальный элемент вектора
int b = data[4];      // последний элемент (в векторе пять элементов)
data[2] = -3;         // меняем элемент с индексом 2 на -3
```

### Функция size
Для получения количества элементов используется функция `size`:
```cpp
std::cout << data.size() << "\n";
```
**Важно:** отрицательные индексы, как в некоторых других языках программирования, в C++ **не допускаются**.

### Проверка корректности индекса
При обращении через квадратные скобки `[]` **проверка корректности индекса не происходит**. Это реализация принципа «мы не должны платить за то, что не используем»:
- Встроенные валидаторы замедляют программу.
- Предполагается, что программист пишет правильный код и уверен, что индекс `i` в выражении `data[i]` неотрицателен и удовлетворяет условию `i < data.size()`.

Если обратиться к вектору по некорректному индексу, программа попадёт в **неопределённое поведение** — фактически она попытается прочитать память, не принадлежащую вектору.

### Функция at
Если вы не уверены в корректности индекса, можно использовать функцию `at`, которая выполняет проверку:
```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
std::cout << data[42] << "\n";      // неопределённое поведение
std::cout << data.at(0) << "\n";    // напечатается 1
std::cout << data.at(42) << "\n";   // произойдёт исключение std::out_of_range
```
При некорректном индексе `at` генерирует исключение `std::out_of_range`, которое можно перехватить и обработать (обработка исключений будет рассмотрена в отдельном параграфе).

### Функции front и back
Эти функции возвращают первый и последний элемент без использования индексов:
```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
std::cout << data.front() << "\n";   // то же, что data[0]
std::cout << data.back() << "\n";    // то же, что data[data.size() - 1]
```
**Важно:** вызов `front()` или `back()` на пустом векторе приводит к **неопределённому поведению**.

### Проверка на пустоту
Для проверки, пуст ли вектор, вместо сравнения `data.size() == 0` принято использовать функцию `empty`:
```cpp
if (!data.empty()) {
    // вектор не пуст, с ним можно работать
}
```

## Итерация по индексам

### Тип size_t
В стандартной библиотеке индексы и размеры контейнеров имеют **беззнаковый тип**. Вместо `unsigned int` или `unsigned long int` используется псевдоним `size_t` (точнее, `std::vector<T>::size_type`). Тип `size_t` совпадает с `uint32_t` или `uint64_t` в зависимости от битности платформы. Его использование подчёркивает, что мы работаем с индексами или размерами.

### Каноническая форма цикла по индексам
Итерацию по элементам с помощью индексов можно записать так:
```cpp
for (size_t i = 0; i != data.size(); ++i) {
    std::cout << data[i] << " ";
}
```
Это **каноническая форма** записи такого цикла:
- Используется сравнение `!=`.
- Используется **префиксный** `++i`.

Для целых чисел разницы с другими вариантами (например, `<` и постфиксный `i++`) нет, но для итераторов других контейнеров разница появится. Рекомендуется привыкать к такой форме записи.

### Проблема беззнаковости
По правилам, унаследованным от C, результат арифметических действий над беззнаковым и знаковым типами приводится к **беззнаковому** типу. Поэтому выражение `data.size() - 1` тоже будет беззнаковым. Если `data.size()` равно нулю, то это выражение будет не `-1`, а **максимальным беззнаковым целым** (для 64-битной платформы — `2^64 - 1`).

#### Ошибочный код
Следующий код проверяет наличие подряд идущих дубликатов, но некорректно работает на пустом векторе:
```cpp
for (size_t i = 0; i < data.size() - 1; ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```
На пустом векторе условие `i < data.size() - 1` на первой итерации окажется истинным, и произойдёт обращение к элементам пустого вектора.

#### Правильное решение
Условие можно переписать как `i + 1 < data.size()` или использовать функцию `std::ssize` (C++20), которая возвращает **знаковый** размер:
```cpp
for (std::int64_t i = 0; i < std::ssize(data) - 1; ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate value: " << data[i] << "\n";
    }
}
```

## Добавление и удаление элементов

### Основные операции
В вектор можно эффективно добавлять элементы в конец и удалять их с конца с помощью функций:
- `push_back(x)` — добавляет элемент `x` в конец.
- `pop_back()` — удаляет последний элемент.
- `clear()` — удаляет все элементы из вектора.

### Пример программы
Программа считывает числа с клавиатуры в вектор и удаляет все нули в конце:
```cpp
#include <iostream>
#include <vector>

int main() {
    int x;
    std::vector<int> data;
    while (std::cin >> x) {          // читаем числа, пока не закончится ввод
        data.push_back(x);           // добавляем очередное число в вектор
    }

    while (!data.empty() && data.back() == 0) {
        // Пока вектор не пуст и последний элемент равен нулю
        data.pop_back();             // удаляем этот нулевой элемент
    }
}
```

### Важные замечания
- Добавление элементов в **другие части вектора** или их удаление **неэффективно**, так как требует сдвига соседних элементов.
- У вектора **нет отдельных функций** для добавления или удаления элементов из начала.
- Для таких операций используются общие функции `insert`/`erase` с итераторами (будут рассмотрены позже).

## Резерв памяти

### Принцип хранения
Вектор хранит элементы в памяти в виде **непрерывной последовательности**, друг за другом. При этом в конце последовательности **резервируется дополнительное место** для быстрого добавления новых элементов.

### Реаллокация
Когда резерв заканчивается, при вставке очередного элемента происходит **реаллокация**:
- Элементы вектора копируются в новый, более просторный блок памяти.

**Характеристики реаллокации:**
- Это довольно **дорогая процедура**.
- Если она происходит достаточно редко, её влияние незначительно.
- Если размер нового блока выбирать **в два раза больше** предыдущего, то **амортизационная сложность** добавления элемента будет **константной**.

### Функция capacity
Текущий резерв вектора можно узнать с помощью функции `capacity` (не путать с `size`):
```cpp
data.capacity()
```

### Пример: рост размера и резерва
Программа, в которой в вектор последовательно добавляются элементы и после каждого шага печатается размер и резерв:
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2};
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(3);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(4);
    std::cout << data.size() << "\t" << data.capacity() << "\n";

    data.push_back(5);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
}
```

Вывод программы:
```
2	2
3	4
4	4
5	8
```

**Наблюдения:**
- Размер вектора увеличивается на единицу.
- Резерв **удваивается** после исчерпания.
- При добавлении четвёрки используется имеющийся резерв (реаллокации нет).
- При добавлении тройки и пятёрки происходит реаллокация.

### Функция reserve
Если число элементов известно заранее, можно сразу зарезервировать нужный размер памяти с помощью `reserve`, чтобы избежать реаллокаций при добавлении элементов.

Пример: сначала задаётся число слов, потом сами слова, и их нужно сохранить в вектор:
```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words;

    size_t words_count;
    std::cin >> words_count;

    // Размер вектора остаётся нулевым, меняется только резерв:
    words.reserve(words_count);

    for (size_t i = 0; i != words_count; ++i) {
        std::string word;
        std::cin >> word;
        // Все добавления будут дешёвыми, без реаллокаций:
        words.push_back(word);
    }
}
```

**Важно:** если передать в `reserve` значение **меньше текущего резерва**, то ничего не поменяется — резерв останется прежним.

### reserve vs resize
Эти функции не следует путать:

| Функция | Действие |
|---------|----------|
| `reserve(n)` | Резервирует память на `n` элементов, **не меняя размер** вектора. |
| `resize(n)` | Меняет **количество элементов** в векторе. |

**Особенности `resize`:**
- Если `n` **меньше** текущего размера — лишние элементы в конце удаляются.
- Если `n` **больше** текущего размера — при необходимости происходит реаллокация и добавляются новые элементы с **дефолтным значением** данного типа.

Пример:
```cpp
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    data.reserve(10);   // поменяли резерв, размер остался равным пяти

    data.resize(3);     // удалили последние элементы 4 и 5
    data.resize(6);     // получили вектор 1, 2, 3, 0, 0, 0
}
```

## Многомерные векторы

### Создание матрицы
Вектор векторов позволяет сохранить матрицу (таблицу) целых чисел. На вход программы сначала поступают число строк и число столбцов матрицы, а потом сами элементы построчно:
```cpp
#include <iostream>
#include <vector>

int main() {
    size_t m, n;
    std::cin >> m >> n;   // число строк и столбцов

    // создаём матрицу matrix из m строк, каждая из которых — вектор из n нулей
    std::vector<std::vector<int>> matrix(m, std::vector<int>(n));

    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cin >> matrix[i][j];
        }
    }

    // печатаем матрицу, выводя элементы через табуляцию
    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cout << matrix[i][j] << "\t";
        }
        std::cout << "\n";
    }
}
```
В этом примере матрица создаётся из нулей, а затем элементы заменяются на введённые значения.

## Сортировка вектора

### Подключение
Для сортировки используется заголовочный файл `algorithm`:
```cpp
#include <algorithm>
#include <vector>
```

### Функция sort
Готовая функция `sort` сортирует вектор по возрастанию. Гарантируется, что сложность в худшем случае составляет **O(n log n)**, где `n` — число элементов. Типичные реализации используют алгоритм **Introsort**.

Пример:
```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    // Сортировка диапазона вектора от начала до конца
    std::sort(data.begin(), data.end());

    // получим вектор 1, 1, 2, 3, 4, 5, 6, 9
}
```

### Итераторы
В функцию `sort` передаются **итераторы**, ограничивающие диапазон. В примере выше передаётся диапазон, совпадающий со всем вектором — от начала до конца. Итераторы возвращают функции `begin()` и `end()` (не путать с `front()` и `back()`!). Итераторы можно считать обобщёнными индексами, но они могут использоваться и для контейнеров, не поддерживающих обычную индексацию. Подробнее — в отдельном параграфе.

### Сортировка по убыванию
Для сортировки по убыванию можно передать **обратные итераторы** `rbegin()` и `rend()`:
```cpp
std::sort(data.rbegin(), data.rend());   // 9, 6, 5, 4, 3, 2, 1, 1
```

### ranges::sort (C++20)
В C++20 доступен более элегантный способ сортировки через `std::ranges::sort`:
```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};

    std::ranges::sort(data);   // можно передать сам вектор, а не его диапазоны
}
```

### Лексикографическое сравнение
Для сортировки по умолчанию используется сравнение элементов с помощью оператора `<`. Этот оператор работает и для самих векторов: они сравниваются **лексикографически**. Поэтому можно без проблем отсортировать, например, строки в матрице (векторе векторов целых чисел).

## Строки (std::string)

### Общая характеристика
Контейнер `std::string` можно рассматривать как **особый случай вектора символов** (`std::vector<char>`), имеющий набор дополнительных функций. У строки есть все те же функции, что и у вектора (например, `pop_back` или `resize`).

### Специфические функции строки

#### Добавление (конкатенация)
```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string";

    s += ' ';              // добавляем отдельный символ в конец (аналог push_back)
    s += "functions";      // добавляем строку в конец
    std::cout << s << "\n";   // Some string functions
}
```

#### Выделение подстроки (substr)
```cpp
// подстрока "string" из 6 символов начиная с 5-й позиции
std::string sub1 = s.substr(5, 6);
// подстрока "functions" с 12-й позиции и до конца
std::string sub2 = s.substr(12);
```

#### Поиск (find)
```cpp
size_t pos1 = s.find(' ');          // позиция первого пробела, в данном случае 4
size_t pos2 = s.find(' ', pos1 + 1); // позиция следующего пробела (11)
size_t pos3 = s.find("str");         // вернётся 5
size_t pos4 = s.find("#");           // вернётся std::string::npos
```
Если подстрока не найдена, `find` возвращает специальное значение `std::string::npos`.

### Вставка, замена и удаление подстрок
Эти операции выполняются через указание индекса начала и длины подстроки:
```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string functions";

    // вставка подстроки
    s.insert(5, "std::");
    std::cout << s << "\n";   // Some std::string functions

    // замена указанного диапазона на новую подстроку
    s.replace(0, 4, "Special");
    std::cout << s << "\n";   // Special std::string functions

    // удаление подстроки
    s.erase(8, 5);            // Special string functions
}
```

Аналогичные действия для других контейнеров (например, для вектора) можно выполнить через итераторы (будут рассмотрены в следующих параграфах).

### starts_with и ends_with (C++20)
В C++20 появились удобные функции для проверки префикса или суффикса строки:
```cpp
#include <iostream>
#include <string>

int main() {
    std::string phrase;
    std::getline(std::cin, phrase);

    if (phrase.starts_with("hello")) {
        std::cout << "Greeting\n";
    }

    if (phrase.ends_with("bye")) {
        std::cout << "Farewell\n";
    }
}
```

## Ключевые выводы

### std::vector
- Динамический массив с эффективным добавлением/удалением в конце.
- Доступ по индексу через `[]` (без проверки) или `at()` (с проверкой).
- Основные функции: `push_back`, `pop_back`, `clear`, `size`, `capacity`, `reserve`, `resize`.
- При исчерпании резерва происходит реаллокация (обычно с удвоением capacity).
- `reserve` выделяет память без изменения размера, `resize` меняет размер.

### std::string
- Специализированный контейнер для работы с текстом.
- Имеет все функции вектора плюс дополнительные: `substr`, `find`, `insert`, `replace`, `erase`.
- В C++20 добавлены `starts_with` и `ends_with`.

### Сортировка
- `std::sort` требует итераторы `begin()`/`end()`.
- `std::ranges::sort` (C++20) работает с самим контейнером.
- Сложность O(n log n), используется Introsort.
