# Введение в C++

## Язык программирования C++

> Язык программирования C++ - это представляет высокоуровневый, компилируемый язык программирования общего назначения со статической типизацией.
Своими корнями он уходит в язык C , который был разработан 1969-1973 годах компанией **Bell Laps**, программистом **Деннисом Ритчи**


В начале 1980-х годов Датский программист **Бьерн Страуструп** работал в компании **Bell Laps** разработал C++ как расширение к языку C. Фактически в начале C++, просто дополнял язык C некоторыми возможностями ООП.
Изначально язык назывался "Cи с классами" \
\
С++ является компилируемым языком, а это значит, что компилятор транслирует(переводит) исходный код на С++ в исполняемый файл, который содержит набор машинных инструкций.

### Основный компиляторы
1) g++
2) clang
3) Компилятор от Microsoft VS

### Состав компилятора g++
1) CPP - перепроцессор
2) As - ассемблер
3) g++ - компилятор
4) Id - линкер

### Зачем нужно компилировать исходный файл

Исходный C++ файл - это всего лишь код, но его невозможно запустить как программу и использовать как библиотеку, поэтому каждый исходный файл требует с компилировать в исполняемый файл.

### Этапы компиляции

1) **Препроцессинг** - это макропроцессор который преобразует программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными деректирами
      - Например препроцессор добавляет headerы в код (# include, убирает комментарий)
2) **Компиляция** - преобразование в ассемблерный код. Это промежуточный этап между высокоуровневым языком и машинным кодом
3) **Ассемблирование** - перевод ассемблерного кода в машинный.  \
   **объектный файл** - это созданный ассемблером промежуточный файл, хранящий кусок машинного кода, этот кусок машинного кода, который еще не был связан вмести с другими кускам машинного кода, наз-ся объектным кодом
4) **Компановка** (Компановщик (линкер)) - связывает все объектные файлы и статические библиотеки в единый исполняемый файл, который мы можем запустить
5) **Загрузка**
